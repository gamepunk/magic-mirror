Updates

Changelog for every version.

0.0.2 · 2026-08-30

  • Zooming overhaul: smooth edge & corner resizing, no black bars, anchored corners while scaling
  • Mirror windows now hide the title bar by default (borderless floating layer)
  • Configurable initial window size (15%–80%)
  • Clear in-mirror notices when the source is covered, off-screen, or not updating
  • The window list no longer shows mirror containers themselves

0.0.1 · 2026-08-28

  • Window / region mirroring (circular selection supported)
  • Multiple container modes: one window per mirror / grouped by app / unified container
  • Pin to menu bar, opacity, click-through, scroll-to-zoom
  • Global hotkeys, multilingual, power-saving frame throttling
  • 7-day trial + license activation, Sparkle auto-updates
  • Chrome extension live on the Chrome Web Store
