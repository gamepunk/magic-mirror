Updates

Changelog for every version.

0.0.4 · 2026-09-03

  • Better recording: pause/resume (paused time isn’t counted), live duration shown while recording
  • Multi-display presets: tile all mirrors across every display (or onto the current screen) in one click
  • More intuitive mirrors: a small control bar fades in on hover (close / pin to menu bar / move to screen); enabling click-through for the first time explains how to manage the mirror later
  • Gallery snapping: cards snap to each other with alignment guides while dragging
  • Polished menu-bar thumbnail: smooth hover preview, no flicker, with a hint that it’s clickable
  • Cleaner Settings: frequent options up front, resource-heavy “advanced” ones collapsed; container modes moved into the Mirror page
  • Smarter shortcuts: a hint points you to bind a global hotkey when none is set; recording a combo that collides with system or common tools (Spotlight, Rectangle, …) shows a conflict warning
  • Optional sounds: short cues on recording start/end and successful activation — off by default, respects the system UI-sounds setting
  • Easier activation: license keys are auto-filled from the clipboard; magicmirror://activate/… links activate in one click
  • Chrome extension licensing: the extension is licensed automatically through the desktop app (Native Messaging) — one key covers the Mac plus its extension (Single: 1 Mac + 1 extension · Family: 3+3)
  • License peace of mind: a reminder to deactivate before uninstalling so your device slots aren’t wasted; if you forgot, support can free a slot for you
  • Beta updates: Settings → About has a “Receive Beta Updates” toggle for early adopters (off = stable only)
  • Accessibility: VoiceOver reads menu rows, action buttons and sliders
  • Reliability across displays: mirrors pause/resume automatically when an external display is unplugged; smoother and more energy-efficient for long sessions and recording
  • More automated tests to prevent regressions

0.0.3 · 2026-08-31

  • Window list grouped by desktop: current Space and the others are shown separately, windows on other desktops can be mirrored too
  • Gallery upgraded to a free canvas: drag mirror cards anywhere, they auto-fit their content aspect ratio
  • Container modes apply instantly: switch between one-window-per-mirror / grouped-by-app / unified container in Settings and existing mirrors reorganize on the spot
  • Accurate status notices: no more false “covered” warnings while content updates normally
  • Crisper on multi-display: mirrors capture at each display’s own scaling factor
  • Performance & power: internal state refactor, merged occlusion checks — smoother and lighter
  • Stability: lots of new automated tests to prevent regressions

0.0.2 · 2026-08-30

  • Smoother zooming: resize without jitter or black bars
  • Cleaner mirror windows: borderless by default, content only
  • Customizable initial window size (15%–80%)
  • Clear notices when the picture is unavailable (covered / off-screen / not updating)
  • Other stability and experience improvements

0.0.1 · 2026-08-28

  • Window / region mirroring: mirror any app window, or drag-select any region inside it (circular selection supported)
  • Multiple display modes: one window per mirror / grouped by app / unified window
  • Pin to the menu bar with a live thumbnail, opacity, click-through, scroll-to-zoom
  • Global hotkeys, multilingual, energy-saving mode
  • 7-day free trial + license activation, in-app auto-updates
  • New mirrors open at the configured initial size, borderless by default (picture-in-picture style)
  • Chrome extension live on the Chrome Web Store
