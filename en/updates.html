Updates

Changelog for every version.

0.0.2 · 2026-08-30

  • Smoother zooming: resize without jitter or black bars
  • Cleaner mirror windows: borderless by default, content only
  • Customizable initial window size (15%–80%)
  • Clear notices when the picture is unavailable (covered / off-screen / not updating)
  • Other stability and experience improvements

0.0.1 · 2026-08-28

  • Window / region mirroring: mirror any app window, or drag-select any region inside it (circular selection supported)
  • Multiple display modes: one window per mirror / grouped by app / unified window
  • Pin to the menu bar with a live thumbnail, opacity, click-through, scroll-to-zoom
  • Global hotkeys, multilingual, energy-saving mode
  • 7-day free trial + license activation, in-app auto-updates
  • New mirrors open at the configured initial size, borderless by default (picture-in-picture style)
  • Chrome extension live on the Chrome Web Store
