Help Center

From your first mirror to managing multiple pages — up and running in minutes.

Up and running in three steps

1. Download & grant permission — Get the macOS app (or Chrome extension) and grant screen recording permission.
2. Pick what to mirror — Open from the menu bar and select any window or screen region.
3. Start using it — Live mirroring starts; scroll to zoom and drag it wherever you like.

Extension: multi-select mode

By default each page keeps one mirror — picking again replaces it. To mirror several elements on the same page, enable multi-select mode in the settings; enable cross-page mirroring to put elements from different pages into one window.

Note: each page contributes at most one element; background tabs may capture at a lower frame rate.

Notes

HTTPS required: mirroring uses tab capture, so pages must be HTTPS (Chrome requirement).
Visible area: only the visible page area is captured; if an element scrolls out of view the tile shows a placeholder and resumes automatically when it's back.
Privacy: everything is processed locally in your browser — nothing is uploaded or stored. See the privacy policy.
