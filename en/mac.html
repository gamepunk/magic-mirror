macOS App

Mirror any window or screen region into floating on-top windows.

Download

Or install with Homebrew

brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror

Features

Window / region mirroring — mirror any app window, or drag-select any region inside it (circular selection supported).
Multiple container modes — one window per mirror / grouped by app / unified container.
Pin to the menu bar — live thumbnail in the menu bar, click to restore.
Opacity & click-through — adjust opacity and pass clicks through any mirror.
Scroll-to-zoom — zoom on hover, stays crisp when enlarged (dynamic capture resolution).
Global hotkeys — show/hide, mirror frontmost window, capture a region, pin/close/opacity/click-through.
Multilingual — Simplified Chinese / English.

Privacy

All frames are processed locally — no frame data is uploaded or stored. See the privacy policy.
