Magic Mirror macOS App **0.0.1** 正式发布！把屏幕上的任何内容变成实时悬浮镜像。

## 能做什么

- **窗口 / 区域镜像**：镜像任意应用窗口，或拖拽截取窗口内任意区域（支持圆形选区）
- **多容器模式**：每个镜像独立悬浮窗 / 按 App 分组 / 统一容器
- **透明度与点击穿透**：任意镜像可调透明度、可穿透点击
- **滚轮缩放**：悬停缩放，放大保持清晰（动态捕获分辨率）
- **全局快捷键**：显示/隐藏、镜像当前窗口、截取区域、置顶/关闭/透明度/穿透
- **节能**：低电量 / 过热自动降帧

## 如何安装

1. 从[官网下载页](/magic-mirror/zh/mac/)下载 DMG（或 ZIP）
2. 打开镜像文件，把 **Magic Mirror** 拖入「应用程序」
3. 首次使用在「系统设置 → 隐私与安全性 → 屏幕录制」中授权并重启

也可以用 Homebrew 安装：

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```
