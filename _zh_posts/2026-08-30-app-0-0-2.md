Magic Mirror macOS App **0.0.2** 发布！画面更清晰，缩放更流畅。

## 本次更新

- **缩放更流畅**：放大缩小不再抖动，画面清晰无黑边
- **镜像窗口更清爽**：默认无边框，只显示镜像内容（画中画风格）
- **初始窗口大小可自定义**：新建镜像时按 15%–80% 的比例自适应显示
- **画面不可用时明确提示原因**：窗口被遮挡 / 不在屏幕 / 内容未更新，一眼看懂
- **稳定性与体验优化**：修复多处细节问题

## 如何安装 / 更新

1. 从[官网下载页](/magic-mirror/zh/mac/)下载 DMG（或 ZIP）
2. 打开镜像文件，把 **Magic Mirror** 拖入「应用程序」
3. 已安装旧版本会通过应用内自动更新提示，也可手动检查更新

也可以用 Homebrew 安装：

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```
