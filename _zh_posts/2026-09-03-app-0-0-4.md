Magic Mirror macOS App **0.0.4** 发布！录制更顺手、多屏一键平铺、悬停即显的控制条——以及一份激活码同时覆盖 Mac 和浏览器插件。

## 本次更新

- **录制更顺手**：支持暂停 / 继续，暂停期间不计入时长；录制面板实时显示已录时长
- **多屏分屏预设**：把全部镜像一键平铺到所有显示器（也可只排列到当前屏幕）
- **悬停控制条**：鼠标移到镜像上会浮现小巧的控制条（关闭 / 置顶到菜单栏 / 移动到屏幕），不用靠猜
- **画廊吸附对齐**：自由画布里拖动卡片靠近其他卡片时自动吸附，并显示对齐引导线
- **菜单栏缩略图打磨**：悬停预览淡入淡出、不闪烁
- **快捷键更省心**：录制的组合键若与系统或常用工具（Spotlight、Rectangle 等）撞车，设置页会提醒你
- **激活更省事**：激活码自动从剪贴板填入；`magicmirror://activate/…` 链接一键激活
- **一份激活码，双端通用**：Chrome 插件通过桌面 App 自动获得授权——Single 覆盖 1 台 Mac + 1 个插件，Family 覆盖 3+3
- **测试版更新**：设置 → 关于 可开启「接收测试版更新」，想尝鲜随时可回
- **辅助功能**：VoiceOver 可以完整朗读菜单与各项操作
- **稳定性与功耗**：外接显示器热插拔自动暂停 / 恢复，长时间运行与录制更省电

## 如何安装 / 更新

1. 从[官网下载页](/magic-mirror/zh/mac/)下载 DMG（或 ZIP）
2. 打开镜像文件，把 **Magic Mirror** 拖入「应用程序」
3. 已安装旧版本会通过应用内自动更新提示，也可手动检查更新

也可以用 Homebrew 安装：

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```
