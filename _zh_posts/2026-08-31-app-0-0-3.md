Magic Mirror macOS App **0.0.3** 发布！画廊更聪明、容器模式即时切换、多桌面体验更顺手。

## 本次更新

- **窗口列表按桌面分组**：当前桌面与其余桌面分开显示，其他桌面的窗口也能直接镜像，不用再到处找
- **画廊升级为自由画布**：镜像卡片可以随意拖动摆放，按内容宽高比自适应大小，放大依然清晰
- **容器模式即时生效**：在设置中切换「独立窗口 / 按 App 分组 / 统一容器」，已有镜像立即按新模式重新组织，无需重新创建
- **画面提示更准确**：内容正常更新时不再误报「被遮挡」
- **多屏更清晰**：镜像窗口在副屏上按对应显示器的缩放比捕获，副屏输出更锐利
- **性能与功耗优化**：内部状态重构、遮挡检测合并查询，运行更流畅、更省电
- **稳定性**：新增大量自动化测试，防止功能回归

## 如何安装 / 更新

1. 从[官网下载页](/magic-mirror/zh/mac/)下载 DMG（或 ZIP）
2. 打开镜像文件，把 **Magic Mirror** 拖入「应用程序」
3. 已安装旧版本会通过应用内自动更新提示，也可手动检查更新

也可以用 Homebrew 安装：

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```
