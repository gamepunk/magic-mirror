# Magic Mirror 官网

本仓库托管 Magic Mirror 的 GitHub Pages 网站（`docs/`）。

- 🌐 网站：https://gamepunk.github.io/magic-mirror/
- 🧩 Chrome 扩展源码：https://github.com/gamepunk/magic-mirror-extension
- 🖥️ macOS App 源码：https://github.com/gamepunk/magic-mirror-macos

## 开发

网站为纯静态页面（HTML + CSS + JS），无需构建：

```sh
# 本地预览
python3 -m http.server 8000 --directory docs
```

中英文文案统一维护在 `docs/i18n.js`。
