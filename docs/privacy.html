隐私政策

生效日期：2026 年 8 月 28 日

Magic Mirror（魔镜，下称"本产品"）尊重你的隐私。本政策说明 Chrome 扩展与 macOS App 会访问哪些信息，以及这些信息如何处理。

一句话总结：画面内容完全在本地处理，本产品不收集、不存储、不上传、不出售你的任何画面数据。唯一的例外是 macOS App 崩溃时发送的匿名诊断信息（见下文），且不包含任何画面内容。

适用范围

本政策适用于以下两款产品：

  • Chrome 扩展（Magic Mirror）——在 Chrome 浏览器中把网页区域镜像到悬浮窗。
  • macOS App（Magic Mirror）——把任意窗口或屏幕区域镜像到置顶悬浮窗。

屏幕内容（镜像画面）

当你创建镜像时，产品会读取你所选区域的渲染画面，以便在悬浮窗中显示。

  • 该数据仅用于绘制你请求的镜像，仅在内存中处理。
  • 采集到的画面在设备本地处理，绝不会上传、存储或传输到任何地方。
  • 产品无法读取页面的 DOM、表单数据、剪贴板内容，也不会持久保存任何画面。

标签页标题与网址（仅 Chrome 扩展）

当你把多个页面的内容合并到一个悬浮窗时，扩展会读取加入窗口的标签页的 标题/网址，仅用于在镜像格子上标注来源页面。该信息只用于屏幕上的标签显示，不会被存储或传输。

设置（仅 Chrome 扩展）

扩展在浏览器本地存储设置项（如"多选模式"开关），以便跨会话记住你的偏好。该数据保存在你的设备上，扩展不会在其他地方读取或写入。

崩溃诊断（仅 macOS App）

macOS App 集成了 Sentry 崩溃上报：仅在应用崩溃时，会自动发送一份匿名诊断报告，包含崩溃堆栈、应用版本与系统版本，用于修复问题。不包含任何画面内容、文件或个人信息。正常使用过程中不会发送任何网络请求。

无账号、无统计、无广告

本产品不含任何分析、追踪、广告或第三方代码；没有账号系统、没有后端服务器、不收集任何使用数据。

政策变更

如本政策发生变更，将更新页面顶部的"生效日期"，并在本地址发布新版本。
