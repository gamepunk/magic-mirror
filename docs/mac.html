镜像任意窗口或屏幕区域到多个置顶悬浮窗，随看随用。

下载

下载 DMG（推荐） 下载 ZIP

当前版本 0.1.0 · macOS 26.0+

或者用 Homebrew 安装

运行以下命令即可安装（之后可随新版本自动更新）：
brew tap gamepunk/tap brew install --cask magic-mirror

安装步骤

  1. 解压后把 MagicMirror.app 拖入「应用程序」文件夹。
  2. 首次打开：右键点击应用 → 打开 → 打开。
  3. 在「系统设置 → 隐私与安全性 → 屏幕录制」中授予权限，然后重启应用。

功能

🪟

任意窗口镜像

选择任意打开的窗口或屏幕区域，即刻创建浮动画中画叠加层。

🗂️

多种容器模式

每个镜像独立容器 / 同一 App 聚合一个容器 / 所有镜像统一一个容器。

🔍

滚轮缩放

在镜像上滚动滚轮放大缩小（0.25×–8×），长宽自适应。

🖱️

点击穿透

一键切换，点击穿过悬浮窗与后方内容交互。

⚡

帧率控制

每个镜像 1–60 FPS 可调，画质与资源占用随心平衡。

⌨️

全局快捷键

任意应用内一键显示/隐藏全部镜像，随时调出。

系统要求

系统要求：macOS 26.0+（Tahoe）。首次使用需在「系统设置 → 隐私与安全性 → 屏幕录制」中授予权限。

隐私

所有画面仅在本地处理，不上传、不存储任何画面数据。

仅在应用崩溃时，会向 Sentry 发送一份匿名诊断报告（崩溃堆栈与系统版本），用于修复问题；不包含任何画面内容。详见隐私政策。

Magic Mirror（魔镜）—— 把屏幕上的任何内容变成实时悬浮镜像。所有处理都在本地完成，不上传任何数据。
