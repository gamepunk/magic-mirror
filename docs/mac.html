macOS App

镜像任意窗口或屏幕区域到多个置顶悬浮窗。

功能

  • 任意窗口镜像：选择任意打开的窗口，即刻创建浮动画中画叠加层。
  • 多种容器模式：每个镜像独立容器 / 同一 App 聚合一个容器 / 所有镜像统一一个容器。
  • 滚轮缩放：在镜像上滚动滚轮放大缩小（0.25×–8×）。
  • 点击穿透：一键切换，点击穿过悬浮窗与后方内容交互。
  • 帧率控制：每个镜像 1–60 FPS 可调。

下载

下载 DMG（推荐） 下载 ZIP
  1. 解压后把 MagicMirror.app 拖入「应用程序」文件夹。
  2. 首次打开：右键点击应用 → 打开 → 打开。
  3. 在「系统设置 → 隐私与安全性 → 屏幕录制」中授予权限，然后重启应用。
应用未公证（公证需要付费的 Apple Developer ID），因此首次打开需要一次右键放行，之后即可正常使用。

获取 / 构建

  1. 克隆仓库：git clone https://github.com/gamepunk/magic-mirror-macos.git
  2. 构建并启动：bash scripts/build-app.sh
  3. 或使用 Xcode 打开 Package.swift 直接运行。
系统要求：macOS 13.0+（Ventura）。首次使用需在「系统设置 → 隐私与安全性 → 屏幕录制」中授予权限。

隐私

所有画面仅在本地处理，不收集、不上传、不存储任何数据。

开源仓库：github.com/gamepunk/magic-mirror-macos
