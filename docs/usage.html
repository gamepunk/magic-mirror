使用指南

从开始镜像到多页面管理，几分钟上手。

基本使用

  1. 点击浏览器工具栏上的 Magic Mirror 图标，打开操作面板。
  2. 点击「开始镜像」进入选择模式（页面元素会随鼠标悬停高亮）。
  3. 点击想要镜像的元素 —— 一个悬浮画中画窗口随即出现，实时显示该区域。
  4. 按 Esc（或再次点击「开始镜像」）退出选择模式，镜像会继续运行。
  5. 点击悬浮窗里的镜像格子（或再次点击原页面元素）可移除该镜像；关闭悬浮窗则停止一切。

悬浮窗操作

  • 滚轮缩放：鼠标悬停在格子上滚动滚轮，向上放大、向下缩小（0.25×–8×）。
  • 查看倍数：鼠标悬停时格子右上角会显示当前缩放倍数。
  • 移除：点击格子即可移除该镜像。
  • 查看来源：来自其他页面的镜像，格子左上角会标注来源域名。

把多个页面的内容放进同一个悬浮窗

Chrome 全局只允许一个画中画窗口，但你可以让多个页面共享它：

  1. 在页面 A（比如 OKX）选择余额元素 —— 悬浮窗出现，页面 A 成为「宿主」。
  2. 切到页面 B（比如 TradingView），点击图标 → 开始镜像 → 选择价格元素。
  3. 页面 B 的内容自动加入页面 A 的悬浮窗，两个页面并排实时更新。
  4. 第 3、4……任意多个页面同理，每个页面贡献一个格子。
说明：每个页面最多贡献一个元素；来源页的位置变化会实时同步到悬浮窗；被切到后台的页面，Chrome 会降低其采集帧率，镜像更新可能没那么流畅。

多选模式

默认每个页面只保留一个镜像，重新点选会替换当前镜像。想在同一页面同时镜像多个元素，请在设置页开启「多选模式」（popup → 打开设置，或 chrome://extensions → Magic Mirror → 详情 → 扩展选项）。开启后选择模式保持开启，可以连续点选多个元素，共享一个悬浮窗。

注意事项

  • HTTPS 要求：镜像依赖于标签页采集，页面必须是 HTTPS（Chrome 的硬性要求）。
  • 可视区域：采集的是当前可见的页面区域；如果被镜像的元素滚动出视口，格子会显示占位提示，滚回可见区域后自动恢复。
  • 隐私：所有画面都在本地浏览器内处理，不上传、不存储任何数据。详见隐私政策。

获取 Chrome 扩展

在 Chrome Web Store 搜索 Magic Mirror（即将上架）。

本地开发加载

  1. 克隆仓库：git clone https://github.com/gamepunk/magic-mirror-extension.git
  2. 构建：bun install && bun run build（需要 Bun）
  3. 打开 chrome://extensions，开启「开发者模式」，加载 dist/ 目录
