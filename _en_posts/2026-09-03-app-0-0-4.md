Magic Mirror for macOS **0.0.4** is out: smarter recording, one-click tiling across displays, a hover control bar on mirrors — and one license key now covers both the Mac app and the Chrome extension.

## What’s new

- **Better recording** — pause/resume without counting paused time; the live duration is shown while recording
- **Multi-display presets** — tile all mirrors across every display (or just the current screen) in one click
- **Hover control bar** — moving the mouse over a mirror fades in a compact bar (close / pin to menu bar / move to screen); no more guessing how to manage a mirror
- **Gallery snapping** — drag cards in the free canvas and they snap to neighbors with alignment guides
- **Polished menu-bar thumbnail** — smooth hover preview, no flicker
- **Smarter shortcuts** — recording a combo that collides with system or common tools (Spotlight, Rectangle, …) now shows a warning in Settings
- **Easier activation** — license keys auto-fill from the clipboard, and `magicmirror://activate/…` links activate in one click
- **One license, two platforms** — the Chrome extension is licensed automatically through the desktop app (Native Messaging). Single covers 1 Mac + its extension; Family covers 3+3
- **Beta updates** — opt in via Settings → About → “Receive Beta Updates” when you want to test early
- **Accessibility** — VoiceOver reads the menu and every action
- **Stability &amp; power** — mirrors pause/resume automatically when an external display is unplugged; smoother and lighter for long sessions and recording

## Install / Update

1. Grab the DMG (or ZIP) from the [download page](/magic-mirror/en/mac/)
2. Open the image and drag **Magic Mirror** into Applications
3. Already installed? Sparkle will offer the update in-app — or use Check for Updates

Or install with Homebrew:

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```

## Trial &amp; activation

Magic Mirror offers a **7-day free trial**; after it ends, activate with a license key ([pricing](/magic-mirror/en/pricing/)). All frames are processed locally — your privacy is intact.
