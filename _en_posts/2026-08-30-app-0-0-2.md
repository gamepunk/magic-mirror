Magic Mirror for macOS **0.0.2** is out — crisper picture, smoother zooming.

## What's new

- **Smoother zooming**: resize without jitter, no more black edges when enlarging
- **Cleaner mirror windows**: borderless by default — just the mirrored content, Picture-in-Picture style
- **Customizable initial size**: new mirrors open at 15%–80% of the source window
- **Clear reasons when content is unavailable**: covered window / off-screen / frozen content, shown right inside the mirror
- **Stability & polish**: various bug fixes and refinements

## How to install / update

1. Grab the DMG (or ZIP) from the [download page](/magic-mirror/en/mac/)
2. Open the image and drag **Magic Mirror** into your Applications folder
3. Existing installs get the update automatically via in-app updates (or check manually)

Or install with Homebrew:

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```

## Trial & activation

A **7-day free trial** is included; after it ends, purchase a license key to keep using it ([pricing](/magic-mirror/en/pricing/)). All frames are processed locally — your privacy is safe.
