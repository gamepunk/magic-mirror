Magic Mirror for macOS **0.0.3** is out — a smarter gallery, instant container switching, and better multi-desktop support.

## What's new

- **Window list grouped by desktop**: your current Space and the others are shown separately, so you can mirror windows that live on another desktop without hunting for them
- **Gallery as a free canvas**: drag mirror cards anywhere inside the window — they auto-fit their content's aspect ratio and stay crisp
- **Container modes apply instantly**: switch between *one window per mirror* / *grouped by app* / *unified container* in Settings and existing mirrors reorganize on the spot — no need to recreate anything
- **Accurate status notices**: mirrors no longer show false "covered" warnings while the content is updating normally
- **Crisper on multi-display**: mirrors capture at each display's own scaling factor, so a secondary monitor gets pixel-sharp output
- **Performance &amp; power**: internal state refactor and merged occlusion checks make the app smoother and lighter
- **Stability**: lots of new automated tests to prevent regressions

## How to install / update

1. Grab the DMG (or ZIP) from the [download page](/magic-mirror/en/mac/)
2. Open the image and drag **Magic Mirror** into your Applications folder
3. Existing installs get the update automatically via in-app updates (or check manually)

Or install with Homebrew:

```bash
brew tap gamepunk/tap
brew install gamepunk/tap/magic-mirror
```
