Magic Mirror browser extension **0.0.2** is out — a fresh new popup and cross-page mirroring are here.

## What's new

- **Redesigned popup**: card-grid layout, macOS-style toggles, blue theme, HD logo
- **Cross-page mirroring** (off by default): place elements from *different* pages into one floating window
- **Drag to reorder** mirror tiles inside the window
- **Smarter element picking**: hover highlight + an info bubble showing the element's tag and size — works on complex pages like TradingView
- **More settings**: scroll-to-zoom toggle, max zoom (×4/×8/×12), mirror count limit, frame rate (15/30/60), click-to-remove, dark window
- Window title is always "Magic Mirror"; background follows the system theme (or forced dark)
- Settings moved into the popup — the separate options page is gone
- Removed source labels (no more domain shown on tiles)
- Fixed a crash on special pages

## How to install / update

1. Open the [Chrome Web Store](https://chromewebstore.google.com/detail/jfapgohnocglaaminogpmjgabkokgnfl) and search for **Magic Mirror**
2. Click "Add to Chrome" — updates install automatically
3. Click the toolbar icon, pick a region on the page, and start mirroring

## Privacy

Everything is processed **locally** in your browser — nothing is uploaded or stored.
