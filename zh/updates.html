更新日志

每个版本的变更记录。

0.0.3 · 2026-08-31

  • 窗口列表按桌面分组：当前桌面与其余桌面分开显示，其他桌面的窗口也能直接镜像
  • 画廊升级为自由画布：镜像卡片可随意拖动摆放，按内容宽高比自适应大小
  • 容器模式即时生效：在设置中切换「独立窗口 / 按 App 分组 / 统一容器」，已有镜像立即按新模式重新组织
  • 画面提示更准确：内容正常更新时不再误报「被遮挡」
  • 多屏更清晰：镜像窗口在副屏上按对应显示器的缩放比捕获
  • 性能与功耗优化：内部状态重构、遮挡检测合并查询，运行更流畅、更省电
  • 稳定性：新增大量自动化测试，防止功能回归

0.0.2 · 2026-08-30

  • 缩放更流畅：放大缩小不再抖动，画面清晰无黑边
  • 镜像窗口更清爽：默认无边框，只显示镜像内容
  • 初始窗口大小可自定义（15%–80%）
  • 画面不可用时明确提示原因（窗口被遮挡 / 不在屏幕 / 内容未更新）
  • 其他稳定性与体验优化

0.0.1 · 2026-08-28

  • 窗口 / 区域镜像：镜像任意应用窗口，或拖拽截取窗口内任意区域（支持圆形选区）
  • 多种展示模式：独立悬浮窗 / 按应用分组 / 统一窗口
  • 置顶到菜单栏实时缩略图、透明度、点击穿透、滚轮缩放（放大保持清晰）
  • 全局快捷键、多语言（中 / 英）、节能模式
  • 7 天免费试用 + 许可证激活、应用内自动更新
  • 新镜像默认按「初始窗口大小」适配显示、默认无边框（画中画风格）
  • Chrome 扩展同步上架 Chrome Web Store
