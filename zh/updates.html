更新日志

每个版本的变更记录。

0.0.4 · 2026-09-03

  • 录制更顺手：支持暂停 / 继续，暂停期间不计入时长；录制面板实时显示已录时长
  • 多屏分屏预设：把全部镜像一键平铺到所有显示器（也可排列到当前屏幕）
  • 镜像窗口交互更直观：鼠标悬停浮现控制条（关闭 / 置顶到菜单栏 / 移动到屏幕），首次开启「点击穿透」时会提示后续如何管理该镜像
  • 统一画廊容器支持拖动对齐：靠近其他卡片时自动吸附并显示对齐引导线
  • 菜单栏置顶缩略图：悬停预览淡入淡出、不闪烁，并有描边提示可点击
  • 设置页更清爽：高频选项保留在首页，资源类高级项折叠收纳；「容器模式」归入镜像页
  • 快捷键更省心：未设置全局快捷键时菜单里会提示；录制组合键时若与系统或常用工具（Spotlight、Rectangle 等）默认占用相同，设置页会给出冲突提醒
  • 提示音（可选）：录制开始 / 结束、许可证激活成功时播放短提示音，默认关闭、跟随系统界面音效开关
  • 激活更省事：复制激活码后打开「许可证」页会自动识别填入；支持 magicmirror://activate/… 链接一键激活
  • Chrome 浏览器插件授权：插件通过桌面 App（Native Messaging）自动获得授权，一份激活码覆盖 Mac + 浏览器插件（Single：1 台 Mac + 1 插件；Family：3+3）
  • 许可证更安心：卸载前会提示先反激活、避免白白占用激活名额；若旧设备已卸载且忘记反激活，可联系客服协助释放名额
  • 测试版更新：设置 → 关于 可开启「接收测试版更新」，尝鲜用户能收到测试频道的新版本（关闭即只收正式版）
  • 辅助功能：VoiceOver 可完整朗读菜单列表、操作按钮与调节滑块
  • 稳定性与多屏可靠性：外接显示器热插拔时镜像自动暂停 / 恢复；长时间运行与录制更省电流畅
  • 更多自动化测试，防止功能回归

0.0.3 · 2026-08-31

  • 窗口列表按桌面分组：当前桌面与其余桌面分开显示，其他桌面的窗口也能直接镜像
  • 画廊升级为自由画布：镜像卡片可随意拖动摆放，按内容宽高比自适应大小
  • 容器模式即时生效：在设置中切换「独立窗口 / 按 App 分组 / 统一容器」，已有镜像立即按新模式重新组织
  • 画面提示更准确：内容正常更新时不再误报「被遮挡」
  • 多屏更清晰：镜像窗口在副屏上按对应显示器的缩放比捕获
  • 性能与功耗优化：内部状态重构、遮挡检测合并查询，运行更流畅、更省电
  • 稳定性：新增大量自动化测试，防止功能回归

0.0.2 · 2026-08-30

  • 缩放更流畅：放大缩小不再抖动，画面清晰无黑边
  • 镜像窗口更清爽：默认无边框，只显示镜像内容
  • 初始窗口大小可自定义（15%–80%）
  • 画面不可用时明确提示原因（窗口被遮挡 / 不在屏幕 / 内容未更新）
  • 其他稳定性与体验优化

0.0.1 · 2026-08-28

  • 窗口 / 区域镜像：镜像任意应用窗口，或拖拽截取窗口内任意区域（支持圆形选区）
  • 多种展示模式：独立悬浮窗 / 按应用分组 / 统一窗口
  • 置顶到菜单栏实时缩略图、透明度、点击穿透、滚轮缩放（放大保持清晰）
  • 全局快捷键、多语言（中 / 英）、节能模式
  • 7 天免费试用 + 许可证激活、应用内自动更新
  • 新镜像默认按「初始窗口大小」适配显示、默认无边框（画中画风格）
  • Chrome 扩展同步上架 Chrome Web Store
